# 삭제된 기능은 문서에 남기지 않는다

기능을 지울 때 문서에 "이건 지워졌다" 거나 "나중에 지울 때 함께 정리하라" 같은
서술을 남기지 않는다. 그 기능을 가리키던 문서 항목도 같은 커밋에서 지운다.

## 왜

문서는 지금 있는 것을 설명하는 자리다. 없는 기능에 대한 설명이 남아 있으면 읽는
사람이 그 기능이 있는 줄 알고 찾게 되고, 문서와 코드가 어긋난 채로 굳는다.

**삭제된 경위는 커밋 메시지가 담당한다.** 거기서는 얼마든지 자세히 적어도 된다 —
왜 지웠는지, 무엇을 확인했는지, 되살리려면 무엇이 필요한지. `git log` 로 언제든
찾을 수 있고, 문서를 읽는 사람의 눈앞을 가리지도 않는다.

## 지킬 것

- 코드에서 기능을 지우는 커밋에 **그 기능을 가리키던 문서 항목도 같이** 지운다.
  표의 행, 목록 항목, 절차 문장, 아키텍처 설명 모두 해당한다.
- 지운 자리에 "제거됨", "더 이상 쓰지 않음" 같은 흔적 문구를 새로 넣지 않는다.
- 왜 지웠는지·무엇을 확인했는지는 커밋 메시지 본문에 남긴다.
- 예외는 **그 자체가 기록인 문서**다. 실험 회고나 결과 보고서는 당시 사실을 적은
  것이므로 고치지 않는다. 다만 지금 없는 것을 가리킨다는 점은 밝혀 둔다.
