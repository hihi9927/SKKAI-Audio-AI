# KsponSpeech 샘플 오디오

전체 데이터셋(`evaluation/KsponSpeech/data/`, gitignore됨)에서 발췌한 **오디오 샘플**.

- `KsponSpeech_0001/KsponSpeech_0000NN.pcm` — 학습셋 샘플 20개, raw PCM (s16le, 16 kHz, mono)
- `eval_clean/KsponSpeech_E000NN.pcm` — 평가셋(eval_clean) 샘플 20개 (E00001~E00020), 동일 포맷

재생/확인용 참고 샘플이며, 전체 데이터·전사는 AI-Hub KsponSpeech에서 받는다.
