# x→en — 제안 정책 단독 (CoVoST2 test, min_gap=1 라벨 `auto_run02`)

비교군(punct/syntax/causal_align/alignatt/mu_prefix)은 **이 트랙에서 아직 안 돌렸다.** 여기 있는 건 제안 정책과 그 자체 기준선(무분절 상한 / 기계분절 하한 / 순위를 뺀 `auto_greedy`)뿐이다.

- 세 트랙 모두 타깃이 영어 → 토크나이저 `13a` 동일 → **트랙 간 BLEU 판독이 성립한다.** en→X 표와 다른 점이다.
- 소스 단위는 다르다 (de 어절 / ja·zh 문자). **`T` 값 자체를 트랙 간에 맞대면 안 된다** — 가로축은 강제정렬 실측 지연(ms)이다.
- `auto_greedy_T*` = 같은 마킹에서 **LLM 순위를 빼고** 등간격 절단한 것. `auto_T*` 와의 차이가 순위 이득이다.
- Δ 는 무분절 대비 corpus BLEU 차, 대괄호는 paired bootstrap 95% CI (sacrebleu, n=1000).
- COMET 은 `wmt22-comet-da`. 값이 없는 트랙은 열이 `—` 로 나온다.
