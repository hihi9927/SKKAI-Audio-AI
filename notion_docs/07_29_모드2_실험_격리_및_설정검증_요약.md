## 🔧 작업 내용
- 논문용 실험(ASR/AST)을 기존 공유 인프라(서버 코드, 벤치마크 클라이언트)와 분리해서 관리하는 방향으로 정리. 서버/클라이언트 코드는 최대한 무수정, 대신 `evaluation/LibriSpeech/paper_result/` 아래에 launch 스크립트를 두는 구조로 결정.
- `paper_result/ASR/scripts/serve_mode2.sh`, `run_mode2.sh` 생성. 모드2(always-commit, baseline(1.0.0) 모델) 실험을 고정 플래그로 실행하고, 결과를 `paper_result/ASR/mode2/{scope}/{tag}/`에 저장하도록 구성.
- ASR 실험은 번역이 필요 없으므로 `--target-lang ""`으로 번역(Google Translate) 호출 자체를 스킵하도록 설정. GPT 번역/교정은 기본값이 off라 별도 처리 불필요.
- mode3, mode4, AST로 확장할 것을 고려해 스크립트를 `ASR/scripts/`로 한 번 더 정리(결과 폴더와 스크립트 폴더 분리).
- 실행 시점 자동 검증 도입: `streaming_websocket_server_fsl.py`의 `hello.serverConfig`에 `enable_dot_commit`, `always_commit` 필드 추가(기존 필드는 유지, 추가만). `paper_result/check_server_config.py`를 범용 검증기로 새로 작성 — `--expect key=value` 형태로 어떤 모드/데이터셋에서도 재사용 가능하며, 이 파일 자체는 앞으로 수정할 필요 없음. `run_mode2.sh`에 벤치마크 실행 전 이 검증을 연결해서, 서버 설정이 기대값과 다르면 즉시 중단되도록 함.

## 🐛 발견된 문제 및 해결
- 모드2(always-commit) 여부는 기존 `hello.serverConfig`에 노출되지 않아 클라이언트가 원격 서버의 실제 설정을 검증할 방법이 없었음 → 서버 쪽에 필드 2개 추가해서 해결.

## ⏭ 해결되지 않은 작업
- mode3, mode4용 `serve_modeN.sh` / `run_modeN.sh`는 아직 미작성 (기존 mode2 스크립트를 템플릿으로 재사용 예정).
- AST(번역 포함) 실험 스크립트/폴더 구성 아직 미착수.
